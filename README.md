
# 🎓 UniSync

**A web application that completes all your University needs**

> **UniSync** is an all-in-one campus life platform designed to synchronize essential student services into a single, seamless web application. It bridges the gap between daily campus needs—from tracking lost items to finding study partners—creating a more connected and efficient university experience.

🔗 **Live Demo:** [https://unisyncc.netlify.app/](https://unisyncc.netlify.app/)

---

## 🚀 Overview

UniSync integrates four core modules to address the most common challenges faced by students living and studying on campus. It serves as a centralized hub for campus logistics, social study connections, and personal productivity.

---

## ✨ Core Modules & Features

### 🔍 1. Lost & Found

A campus-wide tracking system to report and recover lost belongings securely.

* **Report Lost Items:** Quickly submit details about missing items.
* **Search & Match:** Check the community database for found items.
* **Real-time Updates:** Track the status of your reported items.

### 🍔 2. Campus Food Tracker

A real-time monitor for cafeteria availability to help students save time between classes.

* **Live Menu Updates:** See exactly what is currently being served.
* **Availability Alerts:** Get notified when popular items are running low.
* **Student Contributions:** Rely on community-driven updates on food status.

### 📚 3. Study Group Finder

A social networking feature to connect students with similar academic goals.

* **Course-Based Matching:** Find partners studying the exact same subjects.
* **Session Scheduling:** Organize study times based on mutual availability.
* **Resource Sharing:** Access a shared platform for notes and study materials.

### 🧠 4. BrainBrew

A personalized productivity tool designed to optimize your study sessions.

* **Energy Level Detection:** Customizes your session based on how you currently feel (Energized, Normal, or Tired).
* **Smart Focus Timer:** Includes Pomodoro, Deep Focus, and Extended Session modes.
* **Ambient Environment:** Curated playlists and background settings to enhance concentration.

## 📦 Installation & Setup

To run this project locally on your machine, follow these simple steps:

**1. Clone the repository:**

```bash
git clone https://github.com/your-username/unisync.git
cd unisync

```

**2. Open the project:**

* You can simply double-click and open `index.html` in your preferred web browser.
* *Alternatively, run it using a local development server (e.g., via Python):*

```bash
python -m http.server 8000

```
